# Vixon Group

Sitio de agencia (Next.js App Router, TypeScript, Tailwind CSS). Paleta en `src/app/globals.css`. Contenido mock en `src/content/`.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Variables opcionales: `NEXT_PUBLIC_SITE_URL`, WhatsApp, `RESEND_API_KEY`, `RESEND_FROM`, `CONTACT_TO`. Sin clave de Resend el formulario entra en modo demo.
